# Лабораторна робота №1. Адаптивна система розпізнавання та кластеризація

Фреймворк: Flask

### Завдання 1. Побудова абсолютних та нормованих векторів ознак

Перше завдання реалізує завантаження та бінаризацію зображення, після чого на нього накладається сітка 5х5 з 25 секторів. Програма рахує кількість чорних пікселів у кожному секторі для створення абсолютного вектора та нормує їх відносно загальної кількості пікселів для створення масштабоінваріантного нормованого вектора.


### Завдання 2. Система розпізнавання за методом порівняння з еталоном

Друге завдання класифікує тестовий образ шляхом його порівняння з 4 еталонними зображеннями класів A, B, C, D. Для кожного файлу будуються вектори ознак за сіткою 5х5, після чого обчислюється відстань Чебишева між нормованим вектором тестового образу та кожним еталоном, а об'єкт відновиться до класу з найменшою відстанню.



### Завдання 3. Система розпізнавання з навчанням та статистичною обробкою кластерів

Третє завдання забезпечує навчання системи на серіях зображень для 3 класів. Програма вираховує вектори для всіх навчальних образів та знаходить геометричний центр кожного класу як їхнє середнє арифметичне. Класифікація тестового об'єкта відбувається за допомогою розрахунку Евклідової відстані до центрів усіх кластерів з вибором найближчого.
