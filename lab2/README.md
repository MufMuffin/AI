# Лабораторна робота №2.  Нейромережеві методи розпізнавання образів

Фреймворк: Flask

### Завдання 1. Реалізувати систему розпізнавання перцептронного типу для випадку двох класів.

Перше завдання реалізує класичний одношаровий персептрон із навчанням з вчителем для бінарної класифікації вхідних образів. Вхідне зображення обробляється шляхом бінаризації та розподілу на сітку 6х6 з 36 секторів для формування нормованого вектора ознак. На основі вхідних даних розраховується зважена сума з урахуванням поточних вагових коефіцієнтів та порогу активації. Якщо класифікація є невірною, вчитель дає сигнал корекції, після чого система перераховує вагові коефіцієнти та поріг за правилом Розенблатта. Навчання продовжується ітеративно на вибірці зображень до досягнення повної роздільності класів і відсутності помилок.


### Завдання 2. Розробити систему розпізнавання на базі штучної нейронної мережі Хопфілда (та Хемінга)

Друге завдання присвячене розпізнаванню та відновленню зашумлених і спотворених образів за допомогою двох типів нейронних мереж. Для кожного вхідного зображення будується вектор ознак за сіткою 6х6, який бінаризується у біполярний формат зі значеннями -1 та 1. У випадку використання мережі Хемінга обчислення відбуваються у два етапи: спочатку розраховується ступінь схожості з трьома еталонами на першому шарі, після чого на шарі MAXNET шляхом ітераційного гальмування визначається єдиний нейрон-переможець. При виборі мережі Гопфілда система будує матрицю ваг за правилом Хебба без самозв'язків та виконує динамічну актуалізацію станів нейронів до досягнення стабільного стану автоасоціативної пам'яті, порівнюючи отриманий атрактор із вихідними еталонами.
